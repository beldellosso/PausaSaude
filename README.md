# Sistema de Registro de Calorias e Jejum

Este projeto é uma aplicação web full-stack desenvolvida como trabalho final da disciplina, permitindo o acompanhamento de consumo calórico e ciclos de jejum intermitente.

> **Aviso Ético:** Este sistema é um exercício acadêmico. A aplicação não substitui orientação médica ou nutricional.

## 🚀 Tecnologias (Stack)
- **Framework:** Next.js 14+ (App Router)
- **Linguagem:** TypeScript
- **Autenticação e Banco de Dados:** Supabase (Postgres)
- **Estilização:** [Tailwind CSS / shadcn/ui / CSS Modules]
- **Gráficos:** [Recharts / Chart.js]
- **Deploy:** Vercel

## 📋 Funcionalidades
- **Autenticação:** Cadastro, login, logout e recuperação de senha.
- **CRUD de Refeições:** Registro completo de refeições (data/hora, descrição, calorias, tipo).
- **Segurança:** Rotas protegidas com RLS (Row Level Security) garantindo que cada usuário acesse apenas os seus dados.
- **Dashboard:** Visualização do histórico e gráfico de progresso calórico.
